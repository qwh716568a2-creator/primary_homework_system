# 小学课后作业系统功能清单

## 1. 文档目标

本文档用于定义小学课后作业系统的 MVP 功能范围、角色权限、业务规则、迭代优先级和验收口径，供产品、设计、研发、测试对齐使用。

## 2. 产品定位

- 产品名称：小学课后作业系统
- 产品目标：围绕教师布置、学生提交、教师批改、家长监督的作业闭环，提升作业触达率、提交率、批改效率和班级管理效率。
- 核心业务主体：学生
- 核心操作角色：教师、学生、家长、管理员

## 3. 角色定义与权限

### 3.1 教师

- 查看自己任教班级和学科的作业数据
- 发布、编辑、撤回作业
- 查看学生提交情况
- 批改作业并要求订正
- 发送催交提醒
- 查看班级统计数据

### 3.2 学生

- 查看本人作业列表和详情
- 提交作业
- 查看批改反馈
- 根据订正要求再次提交

### 3.3 家长

- 查看绑定学生的作业状态
- 接收提醒和批改结果
- 协助学生提交作业
- 查看孩子的历史完成情况

### 3.4 管理员

- 管理学校、班级、学科、学年、教师、学生、家长账号
- 配置教师任教关系和家长绑定关系
- 查看全校或指定范围的数据看板
- 配置通知策略和基础字典

## 4. 业务对象

- 作业
- 作业班级关系
- 学生作业状态
- 作业提交记录
- 批改记录
- 催交通知记录
- 教师班级学科关系
- 学生家长绑定关系

## 5. MVP 功能范围

## 5.1 教师端

### 5.1.1 作业列表

- 按班级、学科、状态、截止时间筛选
- 展示字段：
  - 作业标题
  - 班级
  - 学科
  - 截止时间
  - 已交人数
  - 未交人数
  - 待批改人数
  - 作业状态
- 支持操作：
  - 查看详情
  - 编辑
  - 撤回
  - 催交
  - 进入批改

### 5.1.2 发布作业

- 必填字段：
  - 作业标题
  - 所属学科
  - 作业内容
  - 发布班级
  - 截止时间
  - 提交方式
- 可选字段：
  - 附件
  - 示例图片
  - 是否允许逾期提交
  - 是否允许重复提交
  - 是否需家长确认
- 提交方式支持：
  - 文字
  - 图片
  - 附件
  - 文字加图片

### 5.1.3 作业详情

- 展示作业基础信息
- 展示班级维度总体进度
- 展示学生提交分布：
  - 未提交
  - 已提交待批改
  - 已完成
  - 待订正
  - 逾期提交
- 支持导出名单

### 5.1.4 提交管理与批改

- 支持按状态筛选学生
- 支持查看学生多次提交历史
- 支持以下批改动作：
  - 标记已完成
  - 标记待订正
  - 写评语
  - 评分或等级
  - 添加批注图片
- 批改后通知学生和家长

### 5.1.5 催交

- 一键催交通知未交学生
- 支持按截止前和逾期后分别提醒
- 记录催交时间、接收人、触达结果

### 5.1.6 统计

- 班级作业完成率
- 按时提交率
- 逾期率
- 待订正率
- 教师已批改率

## 5.2 学生端

### 5.2.1 我的作业列表

- 默认展示待完成作业
- 支持切换：
  - 全部
  - 待完成
  - 已提交
  - 待订正
  - 已逾期
- 展示字段：
  - 作业标题
  - 学科
  - 截止时间
  - 当前状态
  - 教师反馈标记

### 5.2.2 作业详情

- 查看作业说明、附件、示例
- 查看提交要求和截止时间
- 查看自己的提交历史和批改历史
- 查看订正要求

### 5.2.3 提交作业

- 支持文字输入
- 支持图片上传
- 支持附件上传
- 支持保存草稿
- 支持提交前预览
- 支持重新提交

## 5.3 家长端

### 5.3.1 孩子作业状态

- 查看已绑定学生当前待完成作业
- 查看是否已提交、是否逾期、是否待订正
- 支持多孩切换

### 5.3.2 协助提交

- 可代学生上传图片、文字、附件
- 系统需记录操作人为家长
- 业务状态仍归属于学生

### 5.3.3 提醒与反馈

- 接收新作业通知
- 接收截止提醒
- 接收批改结果
- 接收订正提醒

## 5.4 管理端

### 5.4.1 组织与账号管理

- 学校管理
- 年级班级管理
- 教师账号管理
- 学生账号管理
- 家长账号管理

### 5.4.2 关系管理

- 教师与班级学科关系配置
- 家长与学生绑定关系配置
- 班主任配置

### 5.4.3 数据看板

- 作业发布数
- 班级完成率
- 年级完成率
- 逾期率
- 活跃教师数
- 活跃学生数

## 6. 核心业务规则

### 6.1 作业规则

- 一条作业可发给一个或多个班级
- 作业一旦发布，即按学生生成作业任务
- 若已有学生提交，教师不可硬删除作业，只可撤回或停用
- 教师修改截止时间后，系统需重算逾期状态

### 6.2 提交规则

- 作业提交业务主体固定为学生
- 实际操作人可以是学生或家长
- 同一学生允许多次提交，默认最新版本为当前有效版本
- 历史提交记录必须可追溯
- 超过截止时间提交需标记为逾期

### 6.3 批改规则

- 批改状态至少包括：
  - 未批改
  - 已完成
  - 待订正
- 标记待订正后，学生需支持再次提交
- 已完成后仍可补充评语，但需保留时间记录

### 6.4 通知规则

- 发布作业后通知家长和学生
- 截止前支持定时提醒
- 逾期后支持催交提醒
- 批改完成后通知相关学生与家长

### 6.5 权限规则

- 学生只能看自己的数据
- 家长只能看绑定学生的数据
- 教师只能看任教范围内的数据
- 管理员按学校或组织范围查看数据

## 7. 边界与异常处理

- 学生无家长绑定时，不影响学生独立使用
- 一个学生可绑定多个家长，但提交主体仍只有一个学生
- 上传过程中网络中断时，需提示重试并避免重复提交
- 图片上传需支持压缩和多图预览
- 低年级场景可默认允许家长代提交，高年级可按学校策略配置

## 8. 验收标准

### 8.1 教师端验收

- 教师 3 分钟内可完成标准作业发布
- 教师能在作业详情页准确看到未交、已交、待订正名单
- 教师可对单个学生完成至少一次批改和一次退回订正操作

### 8.2 学生端验收

- 学生可在列表中快速看到待完成作业
- 学生可完成文字和图片提交
- 学生可查看教师反馈并再次提交

### 8.3 家长端验收

- 家长能查看孩子作业完成状态
- 家长能收到作业发布和批改结果通知
- 家长可代为提交作业，且系统准确记录操作人

### 8.4 管理端验收

- 管理员可完成班级、账号、绑定关系配置
- 管理员能查看基础完成率和活跃数据

## 9. 迭代优先级

### 9.1 P0

- 账号体系与关系绑定
- 教师发布作业
- 学生提交作业
- 家长协助提交
- 教师批改与待订正
- 催交提醒
- 基础统计

### 9.2 P1

- 作业模板
- 批量批改
- 批量催交
- 导出班级作业报表
- 周报/月报

### 9.3 P2

- 错题本
- 学情趋势分析
- 个性化推荐
- AI 辅助评语

## 10. 建议交付顺序

1. 先完成账号和关系模型
2. 再完成教师发布与学生提交主链路
3. 再完成批改、待订正和通知
4. 最后补统计、导出和效率功能
