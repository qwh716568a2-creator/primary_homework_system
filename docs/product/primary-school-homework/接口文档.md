# 小学课后作业系统接口文档

## 1. 文档说明

- 文档目标：定义小学课后作业系统 MVP 阶段的后端接口规范，供前后端联调、测试用例设计和接口评审使用。
- 适用范围：教师端 Web、学生端小程序/H5、家长端小程序/H5、管理端 Web。
- 技术前提：基于 `Java 17 + Spring Boot 3 + MyBatis-Plus + MySQL 8 + Redis + OSS` 的单体模块化架构。
- 接口风格：RESTful + JSON。

## 2. 全局约定

### 2.1 基础信息

- Base URL：`/api`
- 认证方式：`Authorization: Bearer {token}`
- 字符集：`UTF-8`
- 时间格式：`yyyy-MM-dd HH:mm:ss`
- 主键类型：`Long`

### 2.2 通用请求头

| Header | 是否必填 | 说明 |
| --- | --- | --- |
| Authorization | 是 | 登录后颁发的 JWT Token |
| Content-Type | 是 | `application/json` 或 `multipart/form-data` |
| X-Client-Type | 否 | `teacher-web`、`student-app`、`parent-app`、`admin-web` |
| X-Trace-Id | 否 | 链路追踪 ID |

### 2.3 通用响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "9d4b71be8f5b4d6d",
  "timestamp": "2026-04-02 10:30:00"
}
```

说明：

- `code = 0` 表示成功。
- `message` 为用户可读信息。
- `data` 为业务数据。
- `requestId` 用于问题追踪。

### 2.4 分页结构

```json
{
  "list": [],
  "total": 100,
  "pageNo": 1,
  "pageSize": 20
}
```

### 2.5 通用错误码

| 错误码 | 说明 |
| --- | --- |
| 0 | 成功 |
| 40001 | 参数校验失败 |
| 40002 | 非法请求状态 |
| 40003 | 文件类型不支持 |
| 40004 | 文件大小超限 |
| 40101 | 未登录或 Token 失效 |
| 40301 | 无访问权限 |
| 40401 | 数据不存在 |
| 40901 | 数据重复或状态冲突 |
| 50001 | 系统异常 |

### 2.6 状态枚举

#### 作业状态 `homeworkStatus`

| 值 | 说明 |
| --- | --- |
| draft | 草稿 |
| published | 已发布 |
| revoked | 已撤回 |
| closed | 已关闭 |

#### 学生作业状态 `taskStatus`

| 值 | 说明 |
| --- | --- |
| pending | 待完成 |
| submitted | 已提交待批改 |
| revision_required | 待订正 |
| completed | 已完成 |
| overdue | 已逾期未交 |

#### 批改状态 `reviewStatus`

| 值 | 说明 |
| --- | --- |
| unreviewed | 未批改 |
| completed | 已完成 |
| revision_required | 待订正 |

#### 操作人角色 `operatorRole`

| 值 | 说明 |
| --- | --- |
| student | 学生本人 |
| parent | 家长代提交 |

## 3. 认证与账号接口

### 3.1 登录

- 方法：`POST`
- 路径：`/api/auth/login`
- 说明：支持教师、学生、家长、管理员登录。管理员使用登录名，教师和家长使用手机号，学生使用学号。

请求参数：

```json
{
  "account": "13900000002",
  "password": "123456",
  "clientType": "teacher-web"
}
```

参数说明：

- 当 `clientType` 为 `admin-web` 时，`account` 传 `user_account.login_name`。
- 当 `clientType` 为教师端时，`account` 传 `teacher_profile.mobile`。
- 当 `clientType` 为家长端时，`account` 传 `parent_profile.mobile`。
- 当 `clientType` 为学生端时，`account` 传 `student_profile.student_no`。
- 若系统后续支持多学校学生同号场景，建议增加 `schoolId` 参数。

响应示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOi...",
    "expiresIn": 7200,
    "userInfo": {
      "userId": 10001,
      "userName": "张老师",
      "roleType": "teacher",
      "schoolId": 1
    }
  }
}
```

### 3.2 退出登录

- 方法：`POST`
- 路径：`/api/auth/logout`
- 说明：使当前 Token 失效。

### 3.3 获取当前用户信息

- 方法：`GET`
- 路径：`/api/auth/me`
- 说明：返回当前用户的基础资料、角色、数据范围和前端导航权限。

响应 `data` 结构：

```json
{
  "userId": 10001,
  "userName": "张老师",
  "roleType": "teacher",
  "schoolId": 1,
  "permissions": [
    "teacher.homework.list",
    "teacher.homework.publish"
  ]
}
```

## 4. 文件上传接口

### 4.1 上传文件

- 方法：`POST`
- 路径：`/api/files/upload`
- 说明：统一用于作业附件、作业图片、批改图片上传。
- Content-Type：`multipart/form-data`

表单参数：

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| file | File | 是 | 上传文件 |
| bizType | String | 是 | `homework_attachment`、`submission_image`、`submission_file`、`review_image` |

响应示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "fileUrl": "https://oss.example.com/homework/20260402/abc.jpg",
    "fileName": "abc.jpg",
    "fileSize": 204800,
    "contentType": "image/jpeg"
  }
}
```

业务规则：

- 图片仅允许 `jpg`、`jpeg`、`png`。
- 文件大小限制需按配置中心控制，MVP 建议图片不超过 10MB、附件不超过 20MB。

### 5.3 新建作业

- 方法：`POST`
- 路径：`/api/teacher/homeworks`
- 说明：创建草稿或直接发布作业。

请求参数：

```json
{
  "title": "数学口算练习",
  "subjectCode": "math",
  "contentText": "完成课后练习第 3、4 页",
  "classIds": [101, 102],
  "deadlineAt": "2026-04-03 20:00:00",
  "allowLateSubmit": true,
  "allowResubmit": true,
  "needParentConfirm": false,
  "submitTypes": ["text", "image"],
  "attachments": [
    {
      "assetType": "file",
      "assetUrl": "https://oss.example.com/homework/file1.pdf",
      "assetName": "练习题.pdf",
      "assetSize": 102400
    }
  ],
  "publishNow": true
}
```

响应 `data`：

```json
{
  "homeworkId": 1001,
  "status": "published"
}
```

校验规则：

- `title`、`subjectCode`、`classIds`、`deadlineAt`、`submitTypes` 必填。
- `deadlineAt` 必须大于当前时间。
- 若 `publishNow = true`，则创建后需异步生成学生任务并发送通知。

### 5.5 编辑作业

- 方法：`PUT`
- 路径：`/api/teacher/homeworks/{id}`
- 说明：仅允许草稿或未产生提交的作业编辑核心字段。

### 5.6 发布作业

- 方法：`POST`
- 路径：`/api/teacher/homeworks/{id}/publish`
- 说明：将草稿状态作业发布为正式作业。

### 5.7 撤回作业

- 方法：`POST`
- 路径：`/api/teacher/homeworks/{id}/revoke`

请求参数：

```json
{
  "reason": "题目内容需要调整"
}
```

业务规则：

- 若已有学生提交，禁止物理删除，只允许标记为 `revoked`。
- 撤回后学生端不可继续提交，但历史数据保留。

### 5.10 批改作业

- 方法：`POST`
- 路径：`/api/teacher/tasks/{taskId}/reviews`

请求参数：

```json
{
  "submissionId": 80001,
  "reviewStatus": "revision_required",
  "score": 85,
  "scoreLevel": "B",
  "commentText": "计算步骤再检查一下",
  "reviewAssets": [
    {
      "assetType": "image",
      "assetUrl": "https://oss.example.com/review/remark1.png"
    }
  ]
}
```

业务规则：

- `reviewStatus` 仅支持 `completed` 或 `revision_required`。
- 批改完成后需同步更新 `student_homework_task` 聚合状态。
- 批改后需通知学生和家长。

### 5.11 催交作业

- 方法：`POST`
- 路径：`/api/teacher/homeworks/{id}/remind`

请求参数：

```json

  "classId": 101
}
```

说明：

- `remindType` 支持 `pending`、`overdue`。
- 仅向未交或逾期学生及其家长发送提醒。

## 9. 接口与业务规则补充

### 9.1 权限规则

- 学生只能访问自己的作业、提交、批改记录。
- 家长只能访问绑定学生的数据。
- 教师只能访问任教班级和学科范围内的作业。
- 管理员按学校组织范围拥有数据管理权限。

### 9.2 幂等与状态校验

- 批改接口需校验提交记录是否属于当前任务。
- 发布作业接口需防止重复发布。
- 提交接口需校验作业截止时间和重复提交规则。
- 撤回接口需校验作业当前状态。

### 9.3 审计要求

以下接口建议记录操作日志：

- 登录/退出
- 发布作业/编辑作业/撤回作业
- 提交作业
- 批改作业
- 催交通知
- 绑定关系变更

## 10. 联调建议

- 优先联调顺序：
  1. 登录鉴权
  2. 教师发布作业
  3. 学生查看并提交作业
